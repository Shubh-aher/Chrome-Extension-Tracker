The Chrome Extension Time Tracker is a lightweight browser extension developed using React.js, designed to help users monitor how much time they spend on different websites. 
The extension runs in the background and displays the time spent on active tabs throughout the day.

Key features include:

Tracks and displays time spent on each website.

Simple, clean UI built with React.js.

Automatically updates in real-time as users switch tabs.

Stores time data locally for persistent tracking.

Easy to use and install directly from the Chrome toolbar.
